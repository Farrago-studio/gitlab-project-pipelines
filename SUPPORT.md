# Support

Farrago maintains this extension on a best-effort basis.

## Before contacting support

1. Update Visual Studio Code and the extension.
2. Run **Developer: Reload Window**.
3. Confirm that the repository has a GitLab remote.
4. Confirm that the token has `read_api` access, or `api` access for manual jobs.
5. Remove and configure the token again if authentication fails.

## Contact

Send support and bug reports to [contact@farrago.fr](mailto:contact@farrago.fr) or use the [Farrago contact page](https://farrago.fr/contact/).

Include the extension version, VS Code version, GitLab offering (GitLab.com or self-managed), the failing action, and the exact error message. Never send an access token, credential, private job log, or other secret.

Support is available in English and French.
