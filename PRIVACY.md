# Privacy notice

**Last updated: October 8, 2026**

Farrago GitLab Pipelines does not collect telemetry, analytics, advertising identifiers, or usage statistics. It does not send project or pipeline data to Farrago.

## Data processed

The extension reads the configured Git remote to identify the GitLab instance and project. It sends the GitLab access token, project path, pipeline identifiers, and job identifiers directly to the selected GitLab instance through the GitLab API.

The token is stored using VS Code Secret Storage. Pipeline metadata and job lists are held temporarily in extension memory and refreshed during the VS Code session. Job logs are displayed in the local VS Code Output panel.

## Third parties

GitLab processes API requests according to the privacy and security terms of the GitLab instance used by the user. Microsoft may process extension installation and Marketplace usage data under the Visual Studio Marketplace terms. Farrago does not receive either data stream through this extension.
