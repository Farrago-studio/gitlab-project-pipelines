# Changelog

All notable changes to Farrago GitLab Pipelines are documented in this file.

The project follows [Semantic Versioning](https://semver.org/).

## [0.2.1] - 2026-10-08

### Added

- Dedicated Farrago Pipelines Activity Bar view.
- Full-width pipeline dashboard.
- Branch and tag classification and filters.
- Manual job execution with confirmation.
- Job logs in the VS Code Output panel.
- Direct links to GitLab pipeline and job pages.
- Automatic project detection from SSH and HTTPS Git remotes.
- Secure per-instance token storage through VS Code Secret Storage.
- English and French localization.
- Marketplace metadata and Farrago branding.

## [0.2.0] - 2026-10-08

### Added

- Internal dashboard prototype with branch and tag filters.

## [0.1.0] - 2026-10-08

### Added

- Initial internal prototype listing project pipelines and jobs.
